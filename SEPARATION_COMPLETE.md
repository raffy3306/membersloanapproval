## ⚙️ Configuration Files

### Frontend Environment
**File:** `frontend/.env.local`
```env
VITE_LARAVEL_API_URL=http://localhost:8000/api
```

### Backend Environment
**File:** `backend/.env`
```env
DB_DATABASE=members_loan_approval
DB_USERNAME=root
DB_PASSWORD=
JWT_SECRET=<generated by php artisan jwt:secret>
```

## 🚀 Running the Application

### Terminal 1 - Frontend
```bash
cd frontend
npm install
npm run dev
```
→ Runs on `http://localhost:5173`

### Terminal 2 - Backend
```bash
cd backend
composer install
php artisan migrate
php artisan serve
```
→ Runs on `http://localhost:8000`

## ✨ Benefits of This Organization

✅ **Clear Separation**
- Frontend and backend are completely isolated
- Easier to understand codebase structure

✅ **Independent Deployment**
- Frontend can be deployed to static hosting (Vercel, Netlify, S3)
- Backend can be deployed to server independently

✅ **Team Workflow**
- Frontend developers work in `/frontend`
- Backend developers work in `/backend`
- No conflicts or file mixing

✅ **Scalability**
- Easy to containerize separately (Docker)
- Can scale frontend and backend independently

✅ **Build Optimization**
- Frontend builds produce optimized static assets
- Backend deployment is traditional PHP

## 🔗 API Integration

Frontend connects to backend via REST API using `laravelApiClient.ts`:

```
React Components
    ↓
laravelApiClient.ts (30+ functions)
    ↓ HTTP requests
Backend API Controllers
    ↓
Database (MySQL)
```

### Example API Call
```typescript
// frontend/src/services/laravelApiClient.ts
const user = await login({
  email: 'user@example.com',
  password: 'password'
});

// Makes POST request to:
// http://localhost:8000/api/auth/login
```
